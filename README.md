# MarkEdit Base16 Eighties

Base16 Eighties light and dark themes for MarkEdit, based on Chris Kempson’s [Base16 Eighties](https://github.com/chriskempson/base16-default-schemes/blob/master/eighties.yaml) via the [Spacegray Base16 Eighties](https://github.com/SublimeText/Spacegray) Sublime Text theme.

Built using [MarkEdit-theming](https://github.com/MarkEdit-app/MarkEdit-theming).

## Installation

Once published, install this theme from the MarkEdit Extension Registry.

For local development:

```bash
yarn install
yarn build
